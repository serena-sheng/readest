# 漫画翻译 · 交互规格

状态：设计稿（只定义流程、状态、文案与可访问性；视觉与实现由后续接手）
范围：阅读器内的整页漫画图翻译，含嵌字与侧栏两种呈现

## 0. 触发

读者打开一本外文漫画，读到读不懂的对话，想继续读下去，又不愿意离开应用去别处翻译。
第二个触发是"这本书我想一直开着翻译"——这类读者不需要每次被说服，只需要模式被记住。

产品**无法**知道"这一页是外文"：视觉结果里没有源语言字段，检测整页图只能说明它是漫画。
因此任何"检测到外文"的主动提示都是假话，不做。

## 1. 入口与可发现性

| 问题 | 建议 | 理由 |
| --- | --- | --- |
| 工具栏入口只有一个通用图片图标，下面压着 8px 的 `漫/幕/原` 单字。图标读作"看图/图片查看器"，单字低于可辨认尺寸，且"漫"和功能名（漫画）重复，"幕"和实际呈现（页面两侧的译文栏）不符。 | 控件改成能读作"翻译图片里的文字"的图标，与已有文字翻译图标区分。关闭时 tooltip/无障碍名："翻译这一页的漫画文字"；开启时："漫画翻译：嵌字（点击关闭）"。去掉单字角标。 | 32px 的图标槽里，唯一能承载语义的是图标本身；角标既读不清，也不解释模式。可读的 tooltip 是无障碍名与桌面发现的唯一低成本通道。 |
| 控件只在当前页检测到整页图时出现。翻到封面、版权页、章节扉页时按钮消失，相邻按钮位移。 | 本次会话里这本书一旦出现过整页图，就保留槽位；本页无图时置为禁用，tooltip 写"本页没有可翻译的图片"。若整本书/本节从未出现整页图，仍不显示。 | 消失的按钮让人以为功能坏了，也让工具栏跳动；禁用能把"这页没图"解释清楚。永远不显示则避免文字书里出现无意义的按钮。 |
| 首次使用没有任何文字解释，移动端没有 hover，读者不可能猜到。 | 一次性 coach mark：只在漫画页、只在控件可见时出现一次，指向控件；文案"这一页是漫画，要把气泡里的文字翻成{{目标语言}}吗？" 动作 `[翻译这一页]` `[先不用]`。点任意处或 6 秒后消失，同一个用户不再出现。 | 工具栏在沉浸阅读时是隐藏的，仅靠图标无法教会功能。一次就地提示比一整套 onboarding 便宜，也不打断阅读。 |
| 未配置视觉模型时，入口点了只会弹一条 toast，没有下一步。 | 直接进入"配置引导"（见状态 2），主按钮"去设置"。 | 报错不给出路径等于死路，尤其对第一次使用的人。 |
| 漫画本身是外文这一点无法在翻译前得知。 | 不做"检测到外文"的主动弹窗、不做页边横幅；只做首次使用 tip。 | 没有源语言信息就声称检测到外语是编造。宁可少一个入口，也不撒谎。 |

## 2. 主流程

| 步骤 | 读者做什么 | 系统做什么 | 代价 |
| --- | --- | --- | --- |
| 1 | 翻到一页漫画 | 检测整页图，显示翻译控件；首次出现 coach mark | 无 |
| 2 | 点击控件（或 Shift+I） | 无可用模型时进入配置引导；否则按当前选择开始翻译（默认嵌字） | 一次点击 |
| 3 | 等待 | 先查会话缓存，再查持久缓存；命中则立即显示，不出现进度 | 命中时 0 等待 |
| 4 | 等待（未命中） | 250ms 后显示页面顶部进度条；8 秒后补已用时间；可停止 | 一次模型请求（花 token） |
| 5 | 读译文 | 气泡内出现译文（嵌字）或两侧出现译文栏（侧栏）。不发成功 toast | 无 |
| 6 | 继续翻页 | 记住模式；下一页自动翻译；后台预取下一页；命中则瞬时 | 预取同样花 token（静默） |
| 7 | 关闭翻译 | 一键回原图，不确认；模式记为关闭；再次开启直接命中缓存 | 一次点击 |
| 8 | 下次打开这本书 | 恢复上次模式并翻译当前页；不发成功 toast | 无 |

## 3. 状态矩阵

| 状态 | 触发 | 界面显示 | 可执行动作 |
| --- | --- | --- | --- |
| 1. 未翻译 | 打开漫画页，模式为关 | 原图不动；控件是"关"的外观；每个用户一次 coach mark | 点击翻译（默认嵌字）；长按/箭头选侧栏；Shift+I |
| 2. 首次使用·未配置模型 | 点翻译时没有可用视觉模型 | 配置引导弹层：标题"漫画翻译还没连上模型"，正文一句"在设置里添加一个能看图的模型，再回来翻译这一页。" 主按钮"去设置"，次按钮"以后再说" | 去设置；以后再说；Esc 关闭。回到原图，不丢任何东西 |
| 3. 翻译中 | 当前页请求已发出 | 原图保持不动（不压暗、不裁剪）；控件显示进行中且**仍可点击**（等于取消）；250ms 后页面顶部出现进度条"正在翻译这一页…"，8 秒后补"… 12 秒" | 停止；翻页自动取消；Shift+I 取消 |
| 4. 有译文·嵌字 | 返回 n>0，当前为嵌字 | 每个气泡的原文字被译文替换；控件为开；tooltip 写明"嵌字"；无 toast | 点击关闭；打开菜单换侧栏；点气泡看原文（P1）；Shift+I |
| 5. 有译文·侧栏 | 返回 n>0，当前为侧栏；或从嵌字直接切换 | 页面两侧译文 pill，按气泡纵向位置排列；溢出时该列可纵向滚动，顶部/底部有渐隐提示；控件为开 | 滚动某一列；点 pill 看原文并高亮对应气泡（P1）；点击关闭；菜单换嵌字 |
| 6. 无文字 | 请求成功但 n=0 | 原图不动；页面顶部出现 2.5 秒"本页没有文字"；控件**保持开**（模式是偏好，不是本页状态），但页面没有覆盖层 | 无需操作；翻页；菜单仍可切换。不发 toast、不改回关 |
| 7. 失败 | 请求报错 | 原图不动；页面顶部常驻错误条：人话原因 + `[重试]` + `[关闭]`；若这是首次开启，控件回到关，不谎称已开启 | 重试（重新请求）；关闭；翻页清除。不自动消失 |
| 8. 缓存命中 | 本页此前翻译过（会话或持久缓存） | 250ms 内直接出现译文；不显示进度、不闪、不发 toast；其余同状态 4/5 | 同 4/5；P1 菜单提供"重新翻译这一页" |
| 9. 本页无图 | 翻到封面/版权/扉页；本书此前出现过漫画页 | 原图不动；控件保留但禁用，tooltip"本页没有可翻译的图片"；不发 toast | 翻页；下一页自动恢复。若整本书从未出现整页图则控件不显示 |
| 10. 侧栏不可用 | 内容区太窄，或长条漫（高宽比过大） | 实际按嵌字呈现；控件显示嵌字；每次会话一次 4 秒提示"窗口太窄，已改用嵌字。侧栏需要更宽的页面。"；菜单里侧栏一行禁用并写原因 | 加宽窗口后重新选侧栏；菜单；翻页。偏好已改为嵌字，不做"变宽后偷偷恢复" |
| 11. 切页/关闭中途 | 翻译中翻页，或点击关闭 | 请求取消；覆盖层消失；不发 toast；新页若需要翻译则重新进入状态 3 | 无。再次开启回到缓存或重新请求 |
| 12. 恢复上次模式 | 打开一本上次开着翻译的书 | 自动翻译当前页，直接进入状态 3（无 coach mark） | 停止；切换；关闭 |

## 4. 反馈：形式与时长

| 反馈 | 形式 | 位置 | 出现/时长 | 关闭方式 |
| --- | --- | --- | --- | --- |
| 翻译进行中 | 内联进度条（细条 + 一行字 + 停止） | 阅读区顶部居中，不遮气泡主体 | 缓存查询完成且仍未命中后延迟 250ms 出现；持续到结束；8 秒后追加已用秒数 | 停止按钮；翻页；关闭翻译 |
| 成功 | **不显示**。页面内容变化本身就是反馈 | — | — | — |
| 无文字 | 内联提示条 | 阅读区顶部居中 | 2.5 秒后自动消失 | 自动；翻页提前清除 |
| 失败 | 内联错误条（常驻），含原因、重试、关闭 | 阅读区顶部居中 | 立即，直到处理 | 重试；关闭；翻页 |
| 未配置模型 | 引导弹层 | 模态 | 直到选择 | 去设置；以后再说；Esc |
| 侧栏降级 | 内联提示条 | 阅读区顶部居中 | 每次会话一次，4 秒 | 自动 |
| 缓存命中 | 不显示 | — | — | — |
| 预取（含预取失败） | **不显示** | — | — | — |
| 完成播报（读屏） | `aria-live="polite"` 状态区 | 应用 DOM（不在书页 iframe 内） | 一次："第 3 页已翻译，共 4 处。" / "本页没有文字。" | 下一次播报覆盖 |

规则：

- **不用全局 toast**。当前 toast 只有一个槽位，后一条会顶掉前一条；info 类型还会显示在屏幕正中，直接压在画面上。翻译的反馈必须留在页面附近，并且不互相顶掉。
- 不使用"已翻译 N 处"的成功 toast。视觉变化已经足够；开启预取后每翻一页都会触发一次，变成噪音。
- 进度条只在真正需要等待时出现：缓存命中路径不启动计时器，避免闪一下。
- 错误原因必须翻译成人话，不能直接透出服务端文本。映射见文案 deck。
- 预取永远静默，失败也不提示；等读者真的翻到那一页再按正常失败处理。

## 5. 三态按钮 `漫 / 幕 / 原` 的可理解性

| 问题 | 建议 | 理由 |
| --- | --- | --- |
| `漫` 最容易被读成"漫画"，也就是整个功能，而不是"译文放在气泡里"；`幕` 会被读成弹幕——但这里不是弹幕，是页面两侧的译文栏；`原` 是形容词不是动作。三个字都没有动词。 | 面向用户改名：`嵌字` / `侧栏译文`。英文源 key 用 `In-bubble` / `Side column`。内部代码名可以继续叫 danmaku。 | 名字应该描述读者能看到的差别（译文在哪），而不是借一个不准确的圈内词。叫弹幕会让读者期待飘过画面的评论。 |
| 单按钮循环三态：必须记住顺序；想退回上一个要连点两下；无法直接选择；每次切换都没有"还有哪些选项"的线索。 | 拆成一个开关 + 一个显示方式菜单：点击图标 = 开/关；旁边的小箭头（或长按）打开菜单，三行：`关闭翻译`、`嵌字`（译文放进气泡）、`侧栏译文`（译文排在页面两侧），当前项打勾。 | 开关保持"一键关闭"，菜单解决理解和直达；菜单本身就是图例，不需要额外的说明面板。 |
| 关闭时按钮上没有文字说明，开启时只靠一个彩色角标表示状态。 | 开启状态用图标着色 + 实心点/环等非文字方式持续标示；`aria-pressed` 同步；tooltip 和 aria-label 写明"当前：嵌字"。 | 颜色不能是唯一信号（色盲、电子墨水）；状态必须同时存在于视觉、无障碍名和 tooltip。 |
| 加载时按钮整体禁用，读者点不动也无法取消。 | 加载中按钮保持可点，点击 = 停止并回到原图；同时进度条上有明确的"停止"。 | 已经发出去的请求是花 token 的，必须有一条退路。 |
| 读者可能想"先看原文对照"而不是关闭。 | 菜单增加"本页译文对照"（P1），列出原文→译文；不在按钮上再塞第四个状态。 | 对照是偶发需求，放进菜单不增加主流程负担。 |

两种可行流程与取舍：

- 方案 A（推荐）：控件 = 开关 + 箭头菜单。关闭一次点击，选择模式一次点击，工具栏多占一个箭头位置。
- 方案 B：控件只打开一个三行菜单（关闭/嵌字/侧栏）。实现最简单，但关闭要两次点击。
- 推荐 A；若工具栏宽度不允许，退到 B，并用 `Shift+I` 补救一键关闭。

## 6. 窄窗口

判定基于**阅读区内容宽度**，不是视口宽度。侧栏可用的条件是同时满足：

- 单侧栏位至少能放下 6 个汉字一行（按现有窄栏字号计算约 88px）；更窄时 pill 会退化成每行 1–2 个字。
- 画面至少占阅读区的大部分，且不小于一个可读下限；建议阈值：画面 ≥ max(160px, 阅读区宽度的 55%)。

| 内容区宽度（近似） | 行为 |
| --- | --- |
| 宽，画面两侧本来就有空白 | 沿用现有栏位逻辑：栏宽取自然宽度与空白宽度的较小值，不缩小画面 |
| 中（约 400–600px） | 缩窄画面给两侧栏位，但遵守上面的 55% / 160px 下限；栏内字号可用窄档 |
| 窄（栏位算出来 < 88px，约 < 360px 内容区） | **不进入侧栏**：按嵌字呈现，偏好改为嵌字，每次会话提示一次"窗口太窄，已改用嵌字"；菜单里侧栏一行禁用并写原因 |
| 手机竖屏 | 菜单保留"侧栏译文"一行但禁用，写"需要更宽的窗口（可横屏）"，让读者知道有这个能力，而不是凭空消失 |
| 长条漫（高宽比 > 2） | 同样禁用侧栏，理由改为"长条漫请用嵌字"；长条页的两侧栏会变成一条几千像素高的空列 |

明确否掉的方案：

- **不做栏位横滑**。侧栏本来就在画面之外，横滑会与翻页手势冲突，还会把译文滑出视野。
- **不把 40px 栏位硬画出来**。40px 连 3 个汉字都放不下，pill 会变成竖条；宁可换呈现方式。
- 纵向溢出继续用现有滚动 + 上下渐隐提示，这是刻意设计，保留。

## 7. 键盘与无障碍

| 问题 | 建议 | 理由 |
| --- | --- | --- |
| 没有快捷键；已有书签、TTS、段落模式都有。 | `Shift+I` 开关漫画翻译（`Shift+M` 已被 TTS 高亮当前句占用）；写进快捷键表与帮助面板。菜单打开时方向键移动、Enter 选择、Esc 关闭并把焦点还给按钮。 | 与阅读器其他开关对齐；字母 I 对应 image，且已核对现有绑定无冲突；也补偿了菜单方案多出来的一次点击。 |
| 按钮的无障碍名是"漫 · Manga Translation: Bubble"——把内部状态名和单字拼在一起。 | 无障碍名用完整句子："漫画翻译：嵌字，已开启" / "翻译这一页的漫画文字"。加 `aria-pressed`；菜单按钮加 `aria-haspopup="menu"` 与 `aria-expanded`。 | 读屏用户需要知道"现在是什么状态、按下去会发生什么"，而不是一个缩写。 |
| 加载中没有可聚焦的取消入口。 | 进度条里的"停止"是可聚焦按钮；`Esc` 只在焦点位于进度条内时取消，不抢全局 Esc。 | 全局 Esc 已被面板/弹窗占用，抢它会制造新的冲突。 |
| 译文 chip 和气泡只有 `title`（原生 tooltip）；触屏没有 hover，键盘也进不去；chip 还设了 `pointer-events: none`。 | 触屏：点 chip / 点气泡切换显示原文（P1）。键盘：chip 可聚焦、Enter/空格切换原文，无障碍名"译文：…。原文：…。"。若书页 iframe 的 Tab 顺序不可靠，以应用侧"本页译文对照"面板作为主路径。 | `title` 在触屏上不存在，在 iframe 里也不可靠；必须在应用侧提供一条确定可达的路径。 |
| 完成/空结果/失败对读屏不可见。 | 应用 DOM 里放一个 `aria-live="polite"` 状态区，播报"第 N 页已翻译，共 M 处"/"本页没有文字"。失败条用 `role="alert"`，只播报一次。 | iframe 内的覆盖层不保证进入无障碍树，应用侧的状态区才是确定可达的。 |
| chip 文字在画面边缘，背景是任意漫画；当前深色字配半透明白底，对比足够，但电子墨水模式下 blur 与阴影不可用。 | 译文文字与底色的对比至少 4.5:1；电子墨水模式改用不透明底 + 1px 描边，不依赖 blur/阴影表达层次。焦点环在任意画面上都要可见（双层环，深浅底都能看见）。 | 不能靠"模糊 + 阴影"保证可读性；这是 DESIGN.md 的 e-ink-first 约束。 |
| 现有 chip 入场动画是位移；`prefers-reduced-motion` 已处理。 | 保持：减弱动效下无位移动画。进度条在减弱动效下用静态进行中图标，不做循环动画。 | 动效不能是唯一的进行中信号。 |

## 8. 文案 deck

i18n 约束：Readest 用英文串作为 key（key-as-content）。当前功能里 `_('漫画翻译中…')` 这类中文 key 会让非中文语言也看到中文，必须改成英文 key + 各语言翻译。下表给出英文源 key 与中文文案。

### 按钮与菜单

| 位置 | 英文 key | 中文 |
| --- | --- | --- |
| 控件（关） | Translate manga text | 翻译这一页的漫画文字 |
| 控件（开） | Manga translation: {{mode}}. Click to turn off. | 漫画翻译：{{mode}}（点击关闭） |
| 菜单标题 | Display | 显示方式 |
| 菜单项 1 | Turn off translation | 关闭翻译 |
| 菜单项 2 | In-bubble | 嵌字 |
| 菜单项 2 说明 | Translation sits inside each speech bubble. | 译文放进气泡里 |

## 9. 可逆性与花费

| 动作 | 代价 | 退路 |
| --- | --- | --- |
| 翻译一页 | 一次视觉模型调用（token/费用） | 进行中可"停止"；翻页自动取消；关闭翻译取消。已发出的调用可能仍计费 |
| 后台预取下一页 | 静默花费一次调用 | 关闭翻译或翻页会中止尚未发出的预取；预取失败不重试 |
| 切换嵌字/侧栏 | 无（结果复用，不重新请求） | 再点一次即可切回 |
| 关闭翻译 | 无，结果仍在会话/持久缓存 | 再开启立即恢复 |
| 重新翻译（P1） | 一次调用 | 旧结果在成功前继续显示；失败则保留旧结果并提示 |
| coach mark "先不用" | 无 | 不再自动出现；按钮仍在 |

补充：连续出现鉴权失败（401/403）或限流（429）时，本次会话停止预取，避免每次翻页都白花调用。

## 10. 交接给 ui-designer

需要出视觉的界面（都不是新页面）：

1. 阅读器工具栏 · 漫画翻译控件（关 / 进行中 / 开-嵌字 / 开-侧栏 / 禁用）
2. 阅读区顶部的三种内联状态：进行中、无文字、失败（含重试）
3. 显示方式菜单（三行，含禁用行与勾选）
4. 首次使用 coach mark（锚定工具栏控件）
5. 配置引导弹层（可复用现有对话框外壳）
6. 书页内译文 chip 的默认态、查看原文态、焦点态、电子墨水态
7. （P1）本页译文对照面板

不在本次视觉范围：侧栏的栏宽公式、气泡中心分栏、锚点排序、溢出滚动——这些是既定设计，只按第 6 节加最小可用阈值。

## 11. 改动清单

### P0 — 上线前必须

| # | 改动 | 理由 |
| --- | --- | --- |
| 1 | 把所有翻译 toast 换成阅读区顶部的内联状态（进行中/无文字/失败），不再用全局 toast | 全局 toast 单槽位、info 还在屏幕正中，会盖住画面并被后续消息顶掉 |
| 2 | 进度条：缓存查询完成后再延迟 250ms 出现；8 秒后补已用时间；提供"停止"；翻页/关闭取消；加载中控件保持可点 | 现在只有一条 5 秒的居中提示，之后完全无反馈；且加载中无法取消已发出的请求 |
| 3 | 无文字状态：不发成功 toast、不发"已翻译 0 处"；显示 2.5 秒"本页没有文字"；模式作为偏好保留 | 现在会切到"开"但页面没有任何变化，读者会以为坏了 |
| 4 | 失败状态：常驻错误条 + 重试 + 关闭；把网络/密钥/限流/超时/图片过大映射成人话；首次开启失败时控件回到关 | 失败后 toast 消失，读者只能自己再点一次；服务端文本不能直接给用户看 |
| 5 | 未配置模型：弹配置引导（去设置/以后再说），替代 toast | 报错必须给出下一步 |
| 6 | 去掉 8px 单字角标；控件改为开关 + 显示方式菜单；加 `aria-pressed`；开启态用非文字方式持续标示；tooltip 写当前模式 | `漫/幕/原` 不可读、含义错位、循环无法直达；颜色不能是唯一状态信号 |
| 7 | 用户可见名称改为"嵌字 / 侧栏译文"，不再出现"弹幕" | 这个呈现不是弹幕；名字要描述读者看到的差别 |
| 8 | 窄窗守卫：栏位 < 6 字/行或画面低于下限时按嵌字呈现，偏好改为嵌字并提示一次；菜单对应行禁用并写原因 | 现在窄容器会算出 0–40px 栏位甚至静默不画；手机上 360px 内容区会把画面压到 120px |
| 9 | 工具栏槽位稳定：本书出现过整页图后，无图页保留禁用控件；从未出现则不显示 | 按钮忽隐忽现会位移相邻按钮，并被误读为故障 |
| 10 | i18n：所有文案换成英文源 key，补中文翻译；不再用中文串当 key | key-as-content 下，中文 key 会让所有非中文语言也显示中文 |
| 11 | 键盘：`Shift+I` 开关；菜单方向键/Enter/Esc；快捷键写进帮助面板 | 与书签、TTS、段落模式对齐；补偿菜单多出的一次点击 |
| 12 | 无障碍：`aria-live` 播报完成/空结果；失败用 `role="alert"`；chip 可聚焦、Enter 看原文；译文对比度 ≥4.5:1；电子墨水不靠 blur/阴影 | iframe 内的覆盖层不保证进入无障碍树；文字可读性不能依赖半透明层的视觉技巧 |
